Identity Ladder Explorer

Every identity-ladder metric on every dataset, read from the result files of the brain, face and fundus sessions on 6 Nov 2026. Rungs run from the person themself to the dataset mean. A good metric puts the repeat image closest and does not reward the mean, shrinkage or noise.

QC approved CelebA, IMDb-WIKI (face frame v6f) pre-QC QTIM brain (affine only, registration gate not met), GRAPE and PAPILA fundus pre-QC UTIRIS NIR, UTIRIS VIS, UPOL iris (frame P2 accepted 7 Nov; lid-shadow mask sheets not yet re-shown)

Rank tiles

Columns are the rungs in ladder order, the same for every row. The number and colour show the place the metric gives that rung, from 1 (closest to the person, dark teal) to last (farthest, dark orange), taken from the metric's own values. A metric that follows the ladder reads as a smooth teal-to-orange gradient. White noise is always shown. The small pictures above the columns show what each rung puts into the compared window, on a drawn face (no real person): the red box over one brow and eye is replaced, the rest stays the person. Four columns are the controls of the reference tests and are marked [T1] to [T3b]: the repeat image must come out closer than the dataset mean (T1), than the repeat shrunk toward the mean (T2), than a wrong detail (T3a) and than white noise (T3b). The corner flag in those tiles is the test result: green = passed, red = failed (one-sided Wilcoxon on person or family means, Holm within dataset).

Agreement

Left: do two datasets put the rungs in the same order? Spearman ρ of the tile ranks for each metric, averaged over metrics. Right: do two metrics put the rungs in the same order? ρ for each dataset, averaged over datasets. Only rungs both sides have count, at least 5. MSE, RMSE and PSNR give the same order by construction. ArcFace is left out (5 shared rungs on one dataset).

Calibrated score c

Same columns. Each tile is c × 100: the share of 16 matched strangers in the same window that the rung beats (ties count half). 50 means no better than a stranger, 100 means closer than all 16. One computation for every dataset (brain Amendment 12, group 2). The brain file had z, EVT and posterior but no c, so brain and face c were computed here from saved rows; brain z, EVT and posterior and all GRAPE values reproduce their files.

What each metric puts closest

Each row is one metric on one dataset. The rungs are sorted from what the metric calls closest to the person (left) to farthest (right). Nothing is rescaled: the order comes from the metric's own values. A good metric starts with the repeat image and pushes the averages to the right.

Same person: repeat image, other side (mirror or fellow eye), sibling, co-twin. Look-alikes are other people chosen for similarity. Averages: sex-age mean, mean of 2 strangers, dataset mean. The bar marks the level of the 16 strangers. Hover a chip for the value. Brain and fundus are pre-QC; faces are QC approved.

Raw values as small charts

Every metric on every dataset, raw values

One small chart per metric and dataset, in the metric's own units, no rescaling. Left to right the rungs go from the person to strangers. The axis is turned so that up always means closer to the person; for error metrics (MSE, MAE and similar) lower values are drawn higher.

The ladder on one scale

R for every rung: 0 = the target itself, 1 = the mean of 16 strangers. Lower means the metric calls that fill closer to the person. The last column is the identity margin: dataset mean minus repeat. Above 0 the metric sees the person; below 0 it prefers the average.

Common frame: template-level linear alignment (brain affine to MNI, face landmark affine, fundus disc frame), no nonlinear warp, grey level z-scored inside each image's own mask, 16-unit windows; brain = random patches, both sides. One function computes R for every dataset. Not on this scale: PSNR (infinite on the target itself; within a window it orders rungs like MSE), amplitude deviation (no closer/farther direction), MSLE and the PSNR eps / [0,1] variants of the BraTS panel (need the images, not stored in the rows). ACC vs dataset mean has no value for the dataset mean itself; ArcFace is not defined for averaged faces or the mirror. Margin uses the other side where there is no repeat (PAPILA, marked o).

Not identical across datasets: fundus also divides by a background estimate (the MRI analogue is N4), faces have no illumination correction; PAPILA P9 puts 1.6 times more retina into a window than GRAPE P8; PAPILA has no repeat; the GRAPE sex-age mean covers only 37 targets. Brain intervals resample targets (no family column in the rows), faces families, fundus persons. Values reproduce the fundus file exactly and the face file within 0.007.

Which metrics say the same thing

Spearman correlation between metrics in how they order the rungs. Per-target: rank the rungs inside each target and position, then average over cells (Fisher z). Rung-level: rank the aggregate R values of the rungs, so only a handful of points. Clusters use average linkage on 1 − ρ.
